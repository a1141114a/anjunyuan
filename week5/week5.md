# Web Programming Week 05
## 나의 여행 스타일 테스트

### 1. 프로젝트 소개

이번 Week 05 과제에서는 JavaScript의 sessionStorage와 localStorage를 사용하여
간단한 여행 스타일 테스트를 만들었습니다.

사용자가 닉네임을 입력한 후 총 8개의 질문에 답하면,
선택한 답변에 따라 자신의 여행 스타일을 확인할 수 있습니다.

테스트 결과는 다음 세 가지로 나누었습니다.

- 계획형 여행자
- 균형형 여행자
- 자유형 여행자

단순히 질문과 결과만 보여주는 것이 아니라,
테스트 도중 페이지를 새로고침해도 진행 상황을 이어서 할 수 있도록 만들었고,
완료한 테스트 결과는 이전 기록으로 저장되도록 구현했습니다.

### 3. 주제를 선택한 이유

여행을 할 때 사람마다 여행하는 방식이 많이 다르다고 생각했습니다.

어떤 사람은 여행 전에 숙소, 식당, 관광지 등을 미리 정해 두는 것을 좋아하고,
어떤 사람은 여행지에 도착한 후 상황에 따라 자유롭게 움직이는 것을 좋아합니다.

이런 차이를 간단한 질문으로 알아보면 재미있을 것 같아서
'나의 여행 스타일 테스트'를 주제로 정했습니다.


---

### 4. 게임 진행 방법

1. 닉네임을 입력합니다.
2. 테스트 시작 버튼을 누릅니다.
3. 총 8개의 질문에 답합니다.
4. 각 질문에서 자신에게 더 가까운 답변을 선택합니다.
5. 8개의 질문을 모두 완료하면 여행 스타일 결과가 나타납니다.
6. 결과 화면에서는 자신의 점수와 추천 하루 여행 일정을 확인할 수 있습니다.
7. 다시 테스트하기 버튼을 누르면 새로운 테스트를 시작할 수 있습니다.


---

### 5. 직접 만든 질문

테스트에는 총 8개의 질문을 사용했습니다.

#### 질문 1
여행을 준비할 때 나는?

- 출발 전에 일정과 장소를 미리 정한다.
- 큰 계획만 정하고 나머지는 현지에서 결정한다.

#### 질문 2
처음 가는 도시에서 이동할 때 나는?

- 미리 찾아본 경로대로 이동한다.
- 마음에 드는 길이 보이면 일단 가 본다.

#### 질문 3
여행 중 맛집을 고를 때 나는?

- 후기와 평점을 확인하고 방문한다.
- 지나가다가 마음에 드는 곳에 들어간다.

#### 질문 4
예정했던 장소가 갑자기 문을 닫았다면?

- 미리 준비한 다른 장소로 이동한다.
- 주변을 돌아다니며 새로운 장소를 찾는다.

#### 질문 5
숙소를 예약할 때 나는?

- 여행 전에 숙소를 모두 예약한다.
- 상황에 따라 여행 중에도 숙소를 정할 수 있다.

#### 질문 6
여행 사진을 찍을 때 나는?

- 유명한 포토존을 미리 찾아본다.
- 걷다가 마음에 드는 순간을 자유롭게 찍는다.

#### 질문 7
하루 일정이 예상보다 일찍 끝났다면?

- 다음 일정이나 저장해 둔 장소를 찾아간다.
- 카페에 가거나 주변을 천천히 돌아다닌다.

#### 질문 8
내가 생각하는 좋은 여행은?

- 가고 싶었던 곳을 계획대로 많이 보는 여행
- 예상하지 못한 경험을 자유롭게 즐기는 여행


---

### 6. 결과 계산 방법

각 질문에서 자유로운 여행 방식에 가까운 답변을 선택하면
자유 여행 성향 점수가 1점씩 올라가도록 만들었습니다.

총점은 8점입니다.

점수에 따라 결과를 다음과 같이 나누었습니다.

- 0 ~ 2점 : 계획형 여행자
- 3 ~ 5점 : 균형형 여행자
- 6 ~ 8점 : 자유형 여행자

결과 화면에서는 여행 스타일에 대한 간단한 설명과 함께
각 스타일에 맞는 하루 여행 일정도 보여줍니다.


---

### 7. sessionStorage 사용

테스트를 진행하는 동안 다음 정보를 sessionStorage에 저장했습니다.

- 닉네임
- 현재 질문 번호
- 현재 점수
- 선택한 답변
- 테스트 완료 여부

테스트 중간에 페이지를 새로고침해도
저장된 정보를 읽어서 이전에 진행하던 질문부터 계속할 수 있도록 만들었습니다.

8개의 질문을 모두 완료한 후 페이지를 새로고침하는 경우에도
완료 상태를 확인하여 결과 화면을 다시 보여주도록 구현했습니다.

'다시 테스트하기' 버튼을 누르면 기존의 임시 진행 정보를 삭제하고
처음부터 새로운 테스트를 시작할 수 있습니다.


---

### 8. localStorage 사용

완료한 테스트 결과는 localStorage에 저장했습니다.

저장되는 내용은 다음과 같습니다.

- 닉네임
- 자유 여행 성향 점수
- 전체 점수
- 테스트 완료 날짜와 시간

localStorage를 사용했기 때문에
브라우저를 닫았다가 다시 페이지를 열어도 이전 테스트 기록을 확인할 수 있습니다.

시작 화면 아래에는 '이전 테스트 기록' 영역을 만들었습니다.
여러 번 테스트하면 이전 결과들이 계속 저장되어 표시됩니다.

또한 '기록 전체 삭제' 버튼을 추가하여
저장된 완료 기록을 사용자가 직접 삭제할 수 있도록 만들었습니다.
삭제 버튼을 누르면 바로 삭제하지 않고 먼저 확인 메시지가 나타나도록 했습니다.


---

### 9. 테스트한 내용

완성 후 다음 기능들을 직접 테스트했습니다.

- 닉네임 입력 후 테스트가 정상적으로 시작되는지 확인
- 8개의 질문이 순서대로 나타나는지 확인
- 선택한 답변에 따라 점수가 정상적으로 계산되는지 확인
- 점수에 따라 세 가지 결과가 정상적으로 나타나는지 확인
- 테스트 도중 새로고침 후 기존 진행 상태가 복구되는지 확인
- 테스트 완료 후 새로고침해도 결과 화면이 유지되는지 확인
- 다시 테스트하기 버튼을 누르면 처음 화면으로 돌아가는지 확인
- 다시 테스트해도 이전 완료 기록은 남아 있는지 확인
- 브라우저를 닫았다가 다시 열어도 이전 기록이 남아 있는지 확인
- 여러 개의 테스트 기록이 정상적으로 표시되는지 확인
- 기록 전체 삭제 기능이 정상적으로 작동하는지 확인

### 10. AI 사용 및 수정 내용

과제를 진행하면서 코드의 구조를 정리하고,
sessionStorage와 localStorage를 사용하는 방법을 이해하는 과정에서
AI의 도움을 참고했습니다.

특히 페이지를 새로고침했을 때 진행 상황을 복구하는 방법,
완료된 테스트 기록을 localStorage에 저장하고 다시 표시하는 방법,
저장된 기록을 삭제하는 방법을 구현할 때 도움을 받았습니다.

하지만 테스트의 주제와 질문 내용, 선택지, 결과 기준 등은
과제에 맞게 직접 정하고 수정했습니다.

코드를 추가한 후에는 실제 웹페이지에서 직접 테스트하면서
새로고침, 테스트 재시작, 결과 복구, 이전 기록 저장 및 삭제 기능이
정상적으로 작동하는지 하나씩 확인했습니다.

구현 과정에서 코드의 위치 때문에 기능이 예상대로 작동하지 않는 경우도 있었고,
직접 테스트하면서 코드 위치와 저장 방식을 수정했습니다.


---

### 11. 최종 결과

이번 과제를 통해 sessionStorage와 localStorage의 차이를 직접 확인할 수 있었습니다.

sessionStorage는 현재 테스트의 진행 상태를 임시로 저장하는 데 사용했고,
localStorage는 테스트가 끝난 후에도 이전 결과를 남겨 두는 데 사용했습니다.

처음에는 단순한 여행 스타일 테스트였지만,
저장과 복구 기능을 추가하면서 실제 웹페이지에서 상태를 관리하는 방법을
조금 더 이해할 수 있었습니다.
